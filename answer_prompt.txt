你需要根据 `tests.xlsx` 中的所有题目，结合 `documents.txt` 中已经解析好的表格 JSON，逐题生成最终答案。

你只负责回答题目，不要输出解释、分析过程、推理过程、Markdown、代码块、标题、前言或结尾。

---

## 一、输入文件

### 1. tests.xlsx

每一行对应一道题。

各列含义如下：

- 第1列 `id`：题目唯一编号。
- 第2列 `file_name`：该题对应的原始文件名。
- 第3列 `question_type`：题目类型，只可能是：
  - `structure`
  - `extract`
  - `thinking`
- 第4列 `question`：具体问题。
- 第5列 `table_hint`：帮助定位目标表格的提示。该字段可能为空，也可能不完全准确，只能作为辅助信息，不能覆盖表格实际内容。
- 第6列 `answer_format`：最终答案格式，只可能是：
  - `number`
  - `string`
  - `json`
  - `json_array`
- 第7列如果存在 `answer`，不要读取它作为答案依据，也不要修改它。

必须按照 tests.xlsx 中题目的原始顺序逐题回答。

---

### 2. documents.txt

`documents.txt` 保存了各文件中识别出的标准表格 JSON。

不同原始文件使用类似下面的标记分隔：

=== 001.pdf ===
{标准表格 JSON}

=== 002.png ===
{标准表格 JSON}

同一个文件名下面可能存在一张或多张表格。

标准表格 JSON 格式为：

{
  "row_count": 行数,
  "col_count": 列数,
  "cells": [
    {
      "text": "单元格文本",
      "row": 左上角行号,
      "col": 左上角列号,
      "rowspan": 纵向跨度,
      "colspan": 横向跨度
    }
  ]
}

`row` 和 `col` 均从 0 开始。
举个例子：

{
  "row_count": 4,
  "col_count": 3,
  "cells": [
    {
      "text": "项目",
      "row": 0,
      "col": 0,
      "rowspan": 2,
      "colspan": 1
    },
    {
      "text": "金额",
      "row": 0,
      "col": 1,
      "rowspan": 1,
      "colspan": 2
    },
    {
      "text": "2025年",
      "row": 1,
      "col": 1,
      "rowspan": 1,
      "colspan": 1
    },
    {
      "text": "2026年",
      "row": 1,
      "col": 2,
      "rowspan": 1,
      "colspan": 1
    },
    {
      "text": "销售额",
      "row": 2,
      "col": 0,
      "rowspan": 1,
      "colspan": 1
    },
    {
      "text": "125000",
      "row": 2,
      "col": 1,
      "rowspan": 1,
      "colspan": 1
    },
    {
      "text": "138000",
      "row": 2,
      "col": 2,
      "rowspan": 1,
      "colspan": 1
    }
  ]
}

回答某道题时，首先根据 tests.xlsx 中的 `file_name`，只定位 documents.txt 中对应文件名下面的表格内容。

如果同一文件中有多张表格，再结合 `question` 和 `table_hint` 判断目标表格。

`table_hint` 只是辅助提示；如果它与实际表格内容存在冲突，以实际表格内容和问题本身为准。
 

---

## 二、不同 question_type 的处理方式

### 1. extract

直接读取 documents.txt 中对应文件的标准表格 JSON，根据题目要求定位目标单元格、行、列或区域。

只输出题目要求的最终内容。

不要输出定位过程。

---

### 2. thinking

直接读取 documents.txt 中对应文件的标准表格 JSON。

先在内部定位题目需要的数据，再根据问题完成必要的计算或处理，例如：

- 加总
- 求差
- 计数
- 比例或增长率
- 条件筛选
- 排序
- 最大值或最小值
- 日期、金额、百分比等简单格式归一

只输出最终结果。

不要输出计算过程和解释。

---

### 3. structure

根据 documents.txt 中对应文件的标准表格 JSON 和题目的范围要求，还原表格的真实逻辑结构。

最终必须输出标准表格 JSON：

{
  "row_count": ...,
  "col_count": ...,
  "cells": [...]
}

其中每个单元格只能包含：

- `text`
- `row`
- `col`
- `rowspan`
- `colspan`

必须遵守以下规则：

1. `row_count` 和 `col_count` 始终表示完整目标表格的逻辑总行数和总列数。

2. 如果题目只要求局部结构，例如：
   - 第一行
   - 前3列
   - 前1行和前1列
   - 某一区域

   则 `row_count` 和 `col_count` 仍然填写完整表格的逻辑尺寸，但 `cells` 只输出题目要求范围中的真实单元格。

3. `row` 和 `col` 始终按照完整表格从 0 开始编号，不能因为只恢复局部结构而重新编号。

4. 每个真实单元格只能输出一次。

5. 合并单元格只输出左上角单元格，并使用 `rowspan` 和 `colspan` 表示真实跨度；被合并覆盖的位置不得再次输出。

6. documents.txt 中的表格识别结果可能把原本的合并单元格展开成多个普通单元格。

   如果发现多个相邻单元格：
   - 文本内容完全相同；
   - 单元格尺寸和排列规则一致；
   - 在行方向或列方向连续；
   - 根据表格整体结构、字段含义和相邻单元格关系判断，它们实际应属于同一个合并单元格；

   则应恢复为一个真实合并单元格。

   例如连续四列出现完全相同的标题，并且实际结构明显表示一个横向合并区域，则只保留最左侧单元格，并将其 `colspan` 设置为 4。

   如果连续多行属于一个纵向合并区域，则只保留最上方单元格，并相应增加 `rowspan`。

7. 不要仅仅因为文本相同就盲目合并。

   普通数据区域中，不同行或不同列可能合法地出现相同值。只有根据表格实际结构能够判断这些相邻重复单元格原本属于同一个合并区域时，才能合并。

8. 如果一个合并单元格横跨题目要求的局部范围，其 `rowspan` 和 `colspan` 仍然填写它在完整表格中的真实跨度，不能因为局部输出而截断。

---

## 三、answer_format

必须严格按照 tests.xlsx 第6列 `answer_format` 输出。

### number

只输出最终数字。

例如：

138000

不要添加：
- 单位
- 千分位逗号
- “答案是”
- 其他说明文字

除非题目明确要求单位。

---

### string

只输出最终字符串内容。

例如：

全场景低代码开发平台，支持拖拽式工作流设计。

不得额外加引号或解释文字。

---

### json_array

输出合法的单行 JSON 数组。

例如：

["100","200","300"]

数组元素顺序必须严格按照题目要求。

如果题目要求的某个位置在表格中为空，对应元素填写空字符串：

""

不要输出 Markdown 代码块。

---

### json

输出合法的单行标准表格 JSON。

格式必须为：

{"row_count":...,"col_count":...,"cells":[{"text":"...","row":...,"col":...,"rowspan":...,"colspan":...}]}

不要添加任何其他字段。

不要输出 Markdown 代码块。

---

## 四、最终整体输出格式

必须严格按照以下格式输出所有题目：

第一行："id"+题目的 id 原值  
第二行：该题最终答案  
第三行：下一道题的 id 原值  
第四行：下一道题最终答案  
依次继续，直到最后一道题。

例如：

id1
{"row_count":4,"col_count":5,"cells":[...]}
id2
支持
id3
12
id4
1
id5
["100","200","300"]

注意：

- id 行只输出 id 本身，不要输出 `id:`。
- 每道题严格占两行。
- `json` 和 `json_array` 必须压缩成单行，不能换行。
- `string` 答案也不得包含额外换行。
- 不要在不同题目之间增加空行。
- 不要输出任何题目本身。
- 不要输出任何解释。
- 不要输出 Markdown。
- 不要输出 ```。
- 不要遗漏任何 id。
- 不要重复任何 id。
- 无法确定答案时仍必须输出对应 id；答案无法得到时，答案行输出空字符串，即该行保持为空。

最终输出必须能够被程序直接按照：

id
answer
id
answer
...

的形式逐行解析。
